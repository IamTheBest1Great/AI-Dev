Supervised post-training adapts a pretrained model to respond more usefully to instructions. A model may learn language patterns during pre-training, but that does not automatically make it reliable at following user requests, respecting formatting constraints or behaving like an assistant.

The central idea is:

**Prepare instruction-response examples → train using SFT → evaluate whether the model follows instructions correctly.**

## 1. Instruction-Response Datasets

### Definition

An **instruction-response dataset** contains examples that pair an instruction with a desired response.

The instruction specifies what the model should do, while the response demonstrates the expected output.

```text
Instruction
     ↓
Desired response
```

### Examples

**Example 1 — Explanation**

Instruction:

```text
Explain recursion in simple terms.
```

Desired response:

```text
Recursion is when a function calls itself to solve a problem
by breaking it into smaller versions of the same problem.
```

**Example 2 — Translation**

Instruction:

```text
Translate "Good morning" into Hindi.
```

Desired response:

```text
सुप्रभात
```

**Example 3 — Code generation**

Instruction:

```text
Write a Python function to reverse a string.
```

Desired response:

```python
def reverse_string(s):
    return s[::-1]
```

A training dataset contains many such examples. Depending on the training setup, it may contain thousands, millions or more examples.

### What does this dataset teach?

Instruction-response examples can teach the model:

- How to answer questions.
- How to follow instructions.
- How to format responses.
- How to perform particular tasks.
- How to behave in conversations.
- How to produce useful outputs.

The purpose is not merely to expose the model to additional information. It is also to demonstrate the desired relationship between a user's request and the model's response.

### What makes a good example?

A useful example should have a clear instruction and a correct, relevant response. The response should follow the requested constraints and use the appropriate format.

For example, an instruction requesting exactly three points should have a response containing exactly three points.

### Key takeaway

An instruction-response dataset teaches the model **what kind of response is expected for a given instruction**.

## 2. Demonstrations

### Definition

A **demonstration** is an example that shows how a task should be performed.

It provides the model with a concrete example of the expected behavior.

Think of teaching a student. Instead of merely telling them to solve a problem, you show a problem alongside its correct solution.

```text
Problem:
2 + 2

Correct solution:
4
```

In language-model training, demonstrations follow the same basic principle.

### Examples of demonstrations

**Task behavior**

```text
User:
What is an API?

Assistant:
An API is a way for software systems to communicate
and exchange information.
```

**Formatting behavior**

```text
User:
Return the information as JSON.

Assistant:
{
  "name": "John",
  "age": 30
}
```

**Style behavior**

```text
User:
Explain databases in one short paragraph.

Assistant:
A database is an organized collection of information
that software can store, retrieve, and manage.
```

**Reasoning pattern**

```text
Problem:
A program returns an unexpected result.

Expected response:
1. Identify the observed behavior.
2. Inspect the relevant code.
3. Find the likely cause.
4. Propose and verify a fix.
```

**Conversation behavior**

```text
User:
I do not understand recursion.

Assistant:
Let's start with a simple example...
```

### What can demonstrations teach?

| Demonstration type | Intended behavior |
|---|---|
| Task demonstration | Shows how to complete a task |
| Style demonstration | Shows the expected tone or level of detail |
| Format demonstration | Shows the required output structure |
| Reasoning-pattern demonstration | Shows a useful problem-solving approach |
| Conversation demonstration | Shows how the assistant should respond in context |

### Demonstrations vs. datasets

A demonstration is an individual example of the expected behavior.

An instruction-response dataset is a collection of examples that can be used to train the model.

```text
Individual demonstrations
          ↓
Instruction-response dataset
          ↓
Supervised fine-tuning
```

### Key takeaway

Demonstrations make the desired behavior concrete. They show rather than merely describe what a good response should look like.

## 3. Supervised Fine-Tuning (SFT)

### Definition

**Supervised Fine-Tuning (SFT)** is a training process that adapts a pretrained model using examples of desired inputs and outputs.

The model already has language patterns learned during pre-training. SFT trains it further to respond more appropriately to instructions.

### Why is it called supervised?

SFT uses an expected output, often called the **target response**, against which the model's predicted tokens are evaluated during training.

For example:

```text
Input instruction:
Explain APIs simply.

Target response:
An API is a way for software systems to communicate.
```

The model is trained to make its output more consistent with the target response.

### How SFT works

```text
Pretrained model
       +
Instruction-response dataset
       ↓
Supervised fine-tuning
       ↓
Evaluate model behavior
       ↓
Instruction-following model
```

During training, the model processes the examples and predicts response tokens. The training objective calculates a loss based on the target tokens, and optimization updates the model's parameters.

For many language models, this involves token-level prediction and a language-modeling loss, often computed over the desired response tokens.

### The SFT training loop

```text
Instruction and target response
             ↓
Input tokenization
             ↓
Model predicts response tokens
             ↓
Calculate training loss
             ↓
Backpropagation
             ↓
Update model parameters
             ↓
Repeat over training examples
```

### What is the purpose of SFT?

SFT can improve behaviors such as:

- Following instructions.
- Answering questions.
- Generating summaries.
- Translating text.
- Producing code.
- Classifying information.
- Extracting information.
- Following output-format requirements.
- Responding appropriately in conversations.

The outcome depends on the training examples, their quality and the training setup.

### Important distinction

SFT does not guarantee perfect instruction following. It makes the model more likely to produce desired responses, but it can still misunderstand requests, generate incorrect information or violate constraints.

That is why evaluation is necessary after training.

### Key takeaway

SFT uses supervised examples to shape a pretrained model into a model that is more useful for instruction-following tasks.

## 4. What SFT Actually Changes

SFT can improve the way a model uses its existing capabilities in response to user requests.

### Following instructions

User:

```text
Explain Docker in 3 points.
```

Expected behavior:

- Provide three points.
- Explain Docker accurately.
- Avoid unnecessary detail.

### Following formatting requirements

User:

```text
Return the answer as JSON.
```

Expected behavior:

```json
{
  "topic": "Docker",
  "category": "Containerization"
}
```

The response should satisfy the required JSON structure. In production systems, formatting should also be validated by application code.

### Following style requirements

User:

```text
Explain database indexing to a beginner.
```

Expected behavior:

- Use accessible language.
- Explain unfamiliar terms.
- Include a simple example if helpful.

### Performing specific tasks

SFT can use examples for tasks such as:

| Task | Example instruction |
|---|---|
| Summarization | Summarize this document in two sentences. |
| Translation | Translate this paragraph into Hindi. |
| Classification | Classify this message as positive or negative. |
| Question answering | Answer using the supplied passage. |
| Code generation | Write a Python function to reverse a string. |
| Information extraction | Extract the invoice number and total. |
| Formatting | Return the result as valid JSON. |

### Base model vs. SFT model

| Feature | Base model | SFT model |
|---|---|---|
| Main training | Broad pre-training data | Supervised instruction-response examples |
| Primary learning objective | Learn general patterns from the training distribution | Adapt behavior to desired responses |
| Instruction following | May be inconsistent | Can become more reliable |
| Response formatting | May not consistently follow requests | Can improve with suitable demonstrations |
| Task behavior | General language-model behavior | More task- and instruction-oriented behavior |

A base model can already perform many tasks. SFT does not create every capability from nothing; it adapts the model's behavior using supervised examples.

### Key takeaway

**Pre-training builds the foundation; SFT shapes how that foundation is used to respond to instructions.**

## 5. Instruction-Following Evaluation

### Definition

**Instruction-following evaluation** measures whether a model follows the user's request and satisfies the task's requirements.

A response can sound fluent and still fail the task.

For example:

```text
User:
Give me exactly 3 reasons.

Model:
Here are 7 reasons...
```

The response may be grammatically correct, but it violates the instruction.

### Evaluate multiple dimensions

**Task correctness:** Did the model perform the requested task?

**Answer accuracy:** Is the information correct?

**Instruction adherence:** Did the model follow all requested constraints?

**Format compliance:** Does the output match the required structure?

**Style compliance:** Did the model follow the requested tone and level of detail?

### Example: Multiple constraints

Instruction:

```text
Explain HTTP:
- In exactly 5 bullet points
- For a beginner
- Keep it concise
- Do not use technical jargon
```

The evaluation should check each requirement separately.

| Requirement | What to check |
|---|---|
| Explain HTTP | The requested topic is explained |
| Exactly five points | The response has five bullet points |
| Beginner-friendly | The explanation is accessible |
| Concise | It avoids unnecessary detail |
| No technical jargon | It avoids unexplained specialist terminology |

A model that satisfies only three out of five constraints has not fully followed the instruction.

### Negative constraints

A negative constraint tells the model what it must avoid.

Example:

```text
Do not use technical jargon.
```

Evaluation should check whether the response respects that restriction.

Other examples include:

- Do not exceed 100 words.
- Do not include personal information.
- Do not return anything outside the required JSON object.

### A simple evaluation dataset

For an AI tutor, create prompts such as:

```text
Explain recursion to a beginner.

Summarize a paragraph in exactly 2 sentences.

Return specified information as JSON.

Give exactly 3 examples.

Translate this text into Hindi.

Explain this code and identify the bug.
```

Then compare candidate models using consistent criteria.

```text
Instruction followed?       Yes / No
Answer correct?              Yes / No
Format valid?                Yes / No
All constraints satisfied?   Yes / No
```

Depending on the task, more detailed metrics or human evaluation may also be needed.

### Why evaluation matters

A model may produce fluent language without satisfying the request. Therefore, evaluation must measure both output quality and actual task completion.

### Key takeaway

Do not judge an SFT model only by whether its responses sound good. Check whether it performs the task correctly and follows all the constraints.

## 6. SFT Dataset Quality and Diversity

The quality of the supervised training data strongly influences the behavior that SFT encourages.

### Dataset quality

A useful SFT dataset generally contains:

- Clear instructions.
- Correct target responses.
- Relevant examples.
- Consistent formatting.
- Appropriate difficulty.
- Sufficient coverage of intended tasks.

Poor examples can teach undesirable patterns.

```text
Bad instruction
       +
Incorrect response
       ↓
Unhelpful training signal
```

If the dataset repeatedly demonstrates a wrong answer or an undesirable response pattern, training may reinforce that behavior.

### Dataset diversity

Suppose every example in a dataset asks:

```text
Explain this.
```

The dataset provides limited exposure to different kinds of instructions and output requirements.

A more diverse dataset might include:

- Question answering.
- Summarization.
- Translation.
- Coding.
- Information extraction.
- Classification.
- Reasoning.
- Formatting.
- Multi-turn conversations.

### Why does diversity matter?

Different tasks impose different behavioral requirements.

A summarization task tests whether the model can condense information. A JSON task tests adherence to a structured format. A coding task tests whether it can produce relevant code.

A dataset that covers the application's intended range of tasks gives the model more examples of the desired behaviors.

However, diversity alone is not enough. The examples must also be correct and relevant to the intended application.

### Designing a useful dataset

```text
Define desired behavior
          ↓
Create representative instructions
          ↓
Write accurate target responses
          ↓
Check quality and consistency
          ↓
Include different task types
          ↓
Train using SFT
          ↓
Evaluate on separate test examples
```

### Training data vs. evaluation data

The evaluation set should contain examples that are not simply reused as training targets. This allows the team to test whether the desired behavior generalizes beyond the demonstrations used for training.

### Key takeaway

Good SFT requires both **high-quality examples and appropriate task diversity**.

## 7. Knowledge vs. Behavior

Pre-training and SFT contribute to different aspects of model development.

### Pre-training: Learning patterns

Pre-training exposes the model to large amounts of text and other training data, depending on the model, so it can learn broad statistical patterns.

```text
Large training corpus
         ↓
Pre-training
         ↓
General language-model foundation
```

### SFT: Adapting response behavior

SFT uses curated examples to encourage the model to perform tasks and respond to instructions in particular ways.

```text
Pretrained model
        +
Desired instruction-response examples
        ↓
SFT
        ↓
More instruction-oriented behavior
```

### Example

A base model may have learned many patterns related to databases during pre-training.

A supervised example can teach it how to respond to a request such as:

```text
User:
Explain database indexing to me like I'm a beginner.

Desired assistant response:
Use a simple analogy, explain the purpose of indexing,
and include a short example.
```

The example demonstrates the expected response behavior.

### Important nuance

The distinction between knowledge and behavior is useful for learning, but it is not absolute. SFT can also influence the information a model produces, and pre-training already teaches patterns of text generation and interaction.

The important point is that SFT explicitly trains against examples of the desired responses.

### Key takeaway

Pre-training develops a general foundation, while SFT adapts how the model responds to task-specific instructions.

## 8. Case Study: AI LMS Assistant

Suppose you are developing an AI assistant for a Learning Management System.

The base model already has general familiarity with React, JavaScript, databases and programming. However, you want it to explain course material consistently and help students understand mistakes.

### Define the desired behavior

The assistant should:

- Explain concepts at the student's level.
- Explain why an answer is incorrect.
- Provide the correct concept.
- Generate the requested number of practice questions.
- Follow formatting requirements.

### Create instruction-response examples

**Example 1 — Explain a mistake**

Student instruction:

```text
Why did I get this question wrong?
```

Desired response pattern:

```text
Your answer was incorrect because...
The relevant concept is...
The correct reasoning is...
```

**Example 2 — Explain a topic simply**

Student instruction:

```text
Explain this topic simply.
```

Desired response pattern:

```text
Let's break it down into smaller steps...
```

**Example 3 — Generate practice questions**

Student instruction:

```text
Give me exactly 3 practice questions.
```

Desired response pattern:

```text
1. Question one
2. Question two
3. Question three
```

The actual training examples would need complete, accurate target responses appropriate to the course content.

### Apply SFT

```text
General base model
         ↓
LMS instruction-response dataset
         ↓
Supervised fine-tuning
         ↓
Adapted LMS assistant
```

### Evaluate the result

Test the assistant on examples that were not simply copied from the training dataset.

Check whether it:

- Explains errors accurately.
- Respects the course material supplied to it.
- Uses an appropriate level of explanation.
- Produces the requested number of questions.
- Follows structured-output requirements when applicable.

### Main lesson

SFT can teach the desired tutor behavior, but reliable explanations still require accurate content, representative training data and systematic evaluation.

## 9. Complete SFT Pipeline

The full workflow connects dataset preparation, training and evaluation.

```text
                  PRE-TRAINED MODEL
                         ↓
              Instruction-response dataset
                         ↓
                    Demonstrations
                         ↓
                         SFT
                         ↓
              Instruction-following model
                         ↓
              Instruction-following tests
                         ↓
                 Evaluate the results
                         ↓
           Check accuracy and adherence
                         ↓
              Assess remaining weaknesses
```

### What each stage contributes

| Stage | Purpose |
|---|---|
| Pretrained model | Supplies the general model foundation |
| Instruction-response dataset | Defines desired inputs and outputs |
| Demonstrations | Show concrete examples of appropriate behavior |
| SFT | Updates model parameters using supervised examples |
| Instruction-following tests | Check performance on representative instructions |
| Evaluation | Measures correctness, adherence and formatting |

The final evaluation determines whether the model has improved enough to satisfy the application's requirements. Training completion alone is not sufficient evidence.

## 10. Cheat Sheet and Final Revision

### Core definitions

| Concept | Simple meaning |
|---|---|
| Instruction-response dataset | Collection of instructions paired with desired responses |
| Demonstration | Example showing how a task should be performed |
| SFT | Supervised training on desired input-output examples |
| Target response | The desired output used as a training target |
| Loss | Measure of prediction error under the training objective |
| Backpropagation | Calculation of gradients used to update model parameters |
| Instruction-following evaluation | Testing whether the model follows user instructions |
| Constraint adherence | Whether all specified restrictions are satisfied |
| Dataset diversity | Coverage of different tasks, formats and instruction types |

### Main distinctions

| Concept | Primary purpose |
|---|---|
| Pre-training | Learn general patterns from large-scale training data |
| Continued pre-training | Learn further from additional domain or language data |
| SFT | Adapt the model using supervised examples of desired behavior |
| Evaluation | Check whether the resulting behavior satisfies the requirements |

### Important rules

1. Build clear instruction-response examples.
2. Ensure target responses are accurate and appropriate.
3. Include the task types the application needs to support.
4. Test individual constraints, not just overall fluency.
5. Evaluate on examples separate from the training demonstrations.
6. Monitor correctness, formatting and instruction adherence.
7. Remember that SFT improves behavior but does not guarantee perfect compliance.

### One-line memory trick

**Instruction examples → SFT → improved instruction-following behavior → evaluation to verify that the model actually follows instructions.**

## 11. Practice and Interview Questions

### Easy

**Question 1: What is supervised fine-tuning?**

**Answer:** SFT is a training process that adapts a pretrained model using supervised examples of desired inputs and outputs, making it more likely to respond appropriately to instructions.

**Question 2: What is an instruction-response dataset?**

**Answer:** It is a collection of examples pairing instructions with desired responses. The examples demonstrate the behavior expected from the model.

**Question 3: What is a demonstration?**

**Answer:** A demonstration is an example of how a particular task should be completed, including the expected answer, style or format.

**Question 4: Why is instruction-following evaluation necessary?**

**Answer:** A model can generate fluent language while failing to satisfy the task. Evaluation checks correctness, instruction adherence, formatting and other relevant constraints.

### Medium

**Question 5: How does SFT differ from pre-training?**

**Answer:** Pre-training teaches broad patterns from large-scale data, usually with a self-supervised objective. SFT trains on supervised instruction-response examples to encourage desired task behavior and responses.

**Question 6: Why is dataset diversity important for SFT?**

**Answer:** Different tasks require different behaviors. Including representative examples of summarization, translation, coding, extraction, classification and formatting gives the model broader exposure to the intended instructions.

**Question 7: How would you evaluate an instruction that contains multiple constraints?**

**Answer:** I would define a separate check for each constraint, such as topic correctness, exact number of points, audience level, response length and formatting. I would then measure whether the response satisfies all requirements.

### Hard — Scenario-Based

**Question 8: An SFT model gives fluent answers but repeatedly ignores requests for an exact number of bullet points. What would you investigate?**

**Answer:** I would review the quality and coverage of training examples involving exact-count constraints, check whether target responses consistently satisfy those constraints, and build a separate evaluation set for instruction adherence. I would then compare performance before and after improvements to the training data and setup.

**Question 9: An AI tutor was trained mostly on explanations but performs poorly on JSON extraction tasks. What is a likely issue?**

**Answer:** The SFT dataset may not adequately represent structured extraction behavior. I would add accurate examples for the intended schema and extraction tasks, validate the outputs, and evaluate on separate test examples. I would also use application-side schema validation where required.

**Question 10: A model performs well on the exact prompts used during SFT but poorly on new prompts. What should the team check?**

**Answer:** The team should investigate generalization, training-data diversity and quality, and possible overlap between the training and evaluation examples. It should test on representative unseen prompts and determine whether the dataset covers the range of instructions expected in production.

**Question 11: An LMS assistant is accurate but often provides lengthy answers even when students request concise explanations. How would you address this?**

**Answer:** I would review the training data for examples demonstrating concise responses, including prompts with explicit length constraints. I would evaluate whether the model follows those constraints across different topics and compare results after making targeted training or prompting improvements.

### Multiple-Choice Questions

**Question 12: Which training data is most characteristic of SFT?**

A. Only randomly initialized parameters  
B. Instruction-response examples  
C. Only duplicate webpages  
D. Only evaluation scores  

**Answer:** B. Instruction-response examples.

**Explanation:** SFT uses supervised examples demonstrating the desired outputs.

**Question 13: A response is grammatically correct but provides seven items when the user requested exactly three. What has failed?**

A. Only grammar  
B. Instruction adherence  
C. Tokenization necessarily  
D. Corpus collection  

**Answer:** B. Instruction adherence.

**Explanation:** Fluent language does not compensate for failing an explicit task constraint.

**Question 14: Which is the strongest way to check whether SFT improved instruction following?**

A. Read one training example  
B. Measure performance only on the training set  
C. Test the model on representative held-out instructions and compare results  
D. Assume successful training guarantees success  

**Answer:** C. Test the model on representative held-out instructions and compare results.

**Explanation:** Unseen evaluation examples provide evidence about whether desired behavior generalizes beyond the training demonstrations.

---

## Final Summary

SFT adapts a pretrained model using instruction-response demonstrations. The model learns to produce responses that better match the desired task, style and format.

The complete learning sequence is:

**Pre-training establishes the foundation → supervised examples demonstrate desired behavior → SFT adapts the model → instruction-following evaluation checks the results.**
