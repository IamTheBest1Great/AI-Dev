## Cross-cutting production interview drill

These questions are adapted from the source study guide’s interview section and assess how the individual concepts work together.

**Q45. [Interview] Explain gateway responsibilities to an interviewer.**

**Answer:** Interview answer: Gateway responsibilities addresses the need to normalize provider integration without hiding semantic differences. I would begin with a bounded design for an AI gateway routing between hosted and local models, then specify contracts for Provider abstraction and Model routing. I would measure SLO attainment by route with quality and total cost, verify the actual outcome and demonstrate handling of the primary failure:.


**Q46. [Interview] How would you design Provider abstraction from scratch?**

**Answer:** Interview answer: I would identify the trusted input source, decide which component owns the operation, define typed fields, and specify success and failure states. Adapter interface that reduces superficial API differences without assuming providers behave identically. Then I would create at least a happy-path and an unauthorized/invalid-input test.


**Q47. [Interview] How do Model routing and Fallback interact?**

**Answer:** Interview answer: First define their separate responsibilities. Selection of model/provider using task complexity, privacy, latency, cost and measured quality constraints. Switch to an alternate authorized provider, tool or workflow after defined failure. Re-evaluate schema, quality, privacy and side-effect semantics before treating it as equivalent. I would connect them only through a typed handoff with provenance and an explicit postcondition, rather than allowing hidden state coupling.


**Q48. [Interview] What would you do if Prompt transformation fails in production?**

**Answer:** Interview answer: I would contain the impact, check trace IDs, state and external receipts, then classify the failure as transient, permanent or unknown outcome. I would not blindly repeat a write. After fixing the cause, I would add the incident as a versioned regression case and measure SLO attainment by route with quality and total cost.


**Q49. [Interview] When would you avoid a framework or model for gateway responsibilities?**

**Answer:** Interview answer: When the rules and data contracts are deterministic, a small application service or workflow is usually easier to test and operate. I add an agent or new framework only when variable inputs and evidence show a measurable improvement that offsets extra coordination, cost and risk.


**Q50. [Interview] How would you demonstrate L3 production readiness for M30.1?**

**Answer:** Interview answer: I would present a working repository, a state and permission diagram, the gateway route decision log and compatibility matrix, known limitations, representative evaluation fixtures, failure-injection results and tracing. I would also show restart behavior and an operator takeover path where needed.
