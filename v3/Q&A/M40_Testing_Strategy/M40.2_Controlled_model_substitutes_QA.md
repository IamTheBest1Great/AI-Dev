## Cross-cutting production interview drill

These questions are adapted from the source study guide’s interview section and assess how the individual concepts work together.

**Q21. [Interview] Explain controlled model substitutes to an interviewer.**

**Answer:** Interview answer: Controlled model substitutes addresses the need to separate deterministic correctness from probabilistic task-quality evidence. I would begin with a bounded design for a test framework for agentic AI workflows, then specify contracts for Tool routing and Workflow transitions. I would measure defect detection and real-task completion coverage, verify the actual outcome and demonstrate handling of the primary failure:.


**Q22. [Interview] How would you design Tool routing from scratch?**

**Answer:** Interview answer: I would identify the trusted input source, decide which component owns the operation, define typed fields, and specify success and failure states. Choosing the correct authorized capability for a task; test both tool selection and argument correctness. Then I would create at least a happy-path and an unauthorized/invalid-input test.


**Q23. [Interview] How do Workflow transitions and Error handling interact?**

**Answer:** Interview answer: First define their separate responsibilities. State-machine edges with explicit predicates and allowed next states; reject illegal or skipped transitions. Typed failure classification and recovery rules, including unknown external outcomes and safe fallbacks. I would connect them only through a typed handoff with provenance and an explicit postcondition, rather than allowing hidden state coupling.


**Q24. [Interview] What would you do if State persistence fails in production?**

**Answer:** Interview answer: I would contain the impact, check trace IDs, state and external receipts, then classify the failure as transient, permanent or unknown outcome. I would not blindly repeat a write. After fixing the cause, I would add the incident as a versioned regression case and measure defect detection and real-task completion coverage.


**Q25. [Interview] When would you avoid a framework or model for controlled model substitutes?**

**Answer:** Interview answer: When the rules and data contracts are deterministic, a small application service or workflow is usually easier to test and operate. I add an agent or new framework only when variable inputs and evidence show a measurable improvement that offsets extra coordination, cost and risk.


**Q26. [Interview] How would you demonstrate L3 production readiness for M40.2?**

**Answer:** Interview answer: I would present a working repository, a state and permission diagram, the layered test matrix and regression suite, known limitations, representative evaluation fixtures, failure-injection results and tracing. I would also show restart behavior and an operator takeover path where needed.
