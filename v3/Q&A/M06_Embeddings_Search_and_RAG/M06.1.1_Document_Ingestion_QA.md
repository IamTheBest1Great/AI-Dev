**Answer:** How it connects: Once the format is verified, the job moves to PROCESSING. Instead of flattening everything into plain text—which destroys conditions and relationships—the router sends the file to specialized extractors that preserve structure and coordinates.

## 2. File Uploads and MIME Detection

**Q25. [Conceptual] Explain File Uploads and MIME Detection in simple, interview-ready language.**

**Answer:** The server derives the tenant and actor from authenticated context. It should not trust a freely editable request field that says the uploader belongs to another tenant. The original filename is useful display metadata, but it should not become an unrestricted filesystem path.


**Q26. [Interview] Why does File Uploads and MIME Detection matter, and what is one important design implication?**

**Answer:** An upload interface should create an ingestion job, not immediately mark a document as searchable. The application needs enough information to associate the file with the correct owner and source collection.

## 3. PDF Processing

**Q31. [Conceptual] Explain PDF Processing in simple, interview-ready language.**

**Answer:** A PDF describes how a page should appear. Its internal text order may differ from the order a person reads. A page may contain several columns, positioned text fragments, scanned images, invisible OCR text, vector diagrams and footnotes.

## 4. HTML, Markdown and Office Documents

**Q33. [Conceptual] Explain HTML, Markdown and Office Documents in simple, interview-ready language.**

**Answer:** Consider an article with a menu containing “Installation,” “Maintenance,” and “Troubleshooting.” If those words are repeated on every page, naive extraction makes every page appear relevant to all three topics. Main-content extraction reduces this noise.


**Q34. [Interview] Why does HTML, Markdown and Office Documents matter, and what is one important design implication?**

**Answer:** HTML supplies useful structure: headings, paragraphs, lists, links, tables, code blocks and landmarks. Extraction should identify the main content and distinguish it from navigation, cookie banners, repeated sidebars and unrelated recommendations.

**Answer:** An image may be decorative, a photograph, a screenshot, a technical diagram or a page scan. These roles need different representations.

## 6. Cleaning Without Changing Meaning

**Q41. [Conceptual] Explain Cleaning Without Changing Meaning in simple, interview-ready language.**

**Answer:** Cleaning removes processing noise while preserving source meaning. It is different from summarizing, rewriting or “improving” the author’s instructions.


**Q42. [Interview] Why does Cleaning Without Changing Meaning matter, and what is one important design implication?**

**Answer:** Typical operations include Unicode normalization, line-ending normalization, removal of verified boilerplate, whitespace repair and deduplication of repeated extracted blocks. Each rule should be explicit and versioned.


<a id="8-deduplication-versioning-and-permissions"></a>
## 8. Deduplication, Versioning and Permissions

**Q43. [Conceptual] Explain Deduplication, Versioning and Permissions in simple, interview-ready language.**

**Answer:** Use two hashes when useful: one for raw bytes and one for a clearly defined normalized representation. The normalization algorithm must be versioned; changing it changes what “same content” means.


**Q44. [Interview] Why does Deduplication, Versioning and Permissions matter, and what is one important design implication?**

**Answer:** These decisions have different consequences. Exact byte equality can avoid repeating extraction. Near duplication may justify review, grouping or ranking diversity, but it should not automatically erase a newer revision or a separately governed source.

## 10. Quality Checks and Project Exercise

**Q47. [Conceptual] Explain Quality Checks and Project Exercise in simple, interview-ready language.**

**Answer:** For each source, create a small human-checked reference containing important text, source locations, table relationships, approval state and expected permissions. The reference is an evaluation artifact, not the searchable corpus itself.


**Q48. [Interview] Why does Quality Checks and Project Exercise matter, and what is one important design implication?**

**Answer:** Do not report “100% extraction accuracy” without defining the measured unit. Character accuracy, table-cell accuracy and answer-support completeness measure different things. A single wrong negation can matter more than many harmless punctuation errors.
