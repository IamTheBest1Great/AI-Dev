## 1. Release Lifecycle

**Q1. [Conceptual] Explain Release Lifecycle in simple, interview-ready language.**

**Answer:** The release lifecycle is the process of taking a trained AI model and preparing it so that it can be deployed into production safely, reliably and consistently.


**Q2. [Interview] Why does Release Lifecycle matter, and what is one important design implication?**

**Answer:** Required dependencies are missing. The inference runtime cannot load the model. Quantization reduces output quality. Important capabilities deteriorate. Safety behavior changes unexpectedly. The deployment team cannot identify which model version is running.

## 2. Model Packaging

**Q3. [Conceptual] Explain Model Packaging in simple, interview-ready language.**

## 3. Quantization

**Q9. [Conceptual] Explain Quantization in simple, interview-ready language.**

**Answer:** Quantization reduces the numerical precision used to represent model parameters and, in some approaches, intermediate computations.


**Q10. [Interview] Why does Quantization matter, and what is one important design implication?**

**Answer:** Model parameters are numerical values used by the neural network. Representing them with fewer bits can reduce the amount of memory required.

## 6. Safety Regression Testing

**Q31. [Conceptual] Explain Safety Regression Testing in simple, interview-ready language.**

**Answer:** Capability preservation alone is insufficient. A model can maintain good task accuracy while becoming less safe in certain situations.


**Q32. [Interview] Why does Safety Regression Testing matter, and what is one important design implication?**

**Answer:** Even if the modification is intended to improve efficiency rather than change behavior, safety should be tested again.


<a id="7-versioned-release"></a>
## 7. Versioned Release

**Q33. [Conceptual] Explain Versioned Release in simple, interview-ready language.**

**Answer:** A versioned release assigns a unique, identifiable version to a model artifact so that the team can determine exactly which model is deployed.


**Q34. [Interview] Why does Versioned Release matter, and what is one important design implication?**

**Answer:** Versioning helps teams identify and manage the exact model running in a particular environment.
