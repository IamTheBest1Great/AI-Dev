## 10. Key Takeaways

**Q229. [Conceptual] Explain Key Takeaways in simple, interview-ready language.**

**Answer:** Dense models use dense computational pathways. MoE models route computation to selected experts. Total parameters and active parameters are different quantities. MoE can provide large total capacity without activating every expert for every token. Routing, memory, and communication may offset computational savings.


**Q230. [Interview] Why does Key Takeaways matter, and what is one important design implication?**

**Answer:** MHA gives each standard attention head its own K/V representations. MQA shares one K/V set across multiple Query heads. GQA shares K/V representations within groups of Query heads. Less K/V duplication can reduce KV-cache memory. GQA offers an intermediate design between MHA and MQA.
