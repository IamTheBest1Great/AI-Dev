## Part 1 — Why Build a Minimal Loop First?

**Q13. [Conceptual] Part 1 — Why Build a Minimal Loop First?**

**Answer:** An agent framework can help with integrations, tracing and durable execution, but it does not decide which actions are authorized or what evidence is sufficient for your business. Starting from a small explicit loop clarifies the contract between the model and the runtime.


**Q14. [Interview] How would you justify the answer to “Part 1 — Why Build a Minimal Loop First?” in an interview?**

**Answer:** An LLM is a decision proposer, not an executor of external state changes. The runtime turns a proposed tool invocation into a real, validated call, then records what the tool actually returned.
