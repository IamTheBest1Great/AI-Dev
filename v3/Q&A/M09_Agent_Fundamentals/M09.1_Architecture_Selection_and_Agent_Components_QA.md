## Part 1 — M09.1.1 What Is an Agent?

**Q13. [Conceptual] Part 1 — M09.1.1 What Is an Agent?**

**Answer:** An AI agent is a system in which a model can choose one or more actions based on an objective and observed results, within limits enforced by software. A useful minimal loop is observe → decide → act → observe again → stop. The model may draft the decision, but the application must validate, authorize and execute actions.


**Q14. [Interview] How would you justify the answer to “Part 1 — M09.1.1 What Is an Agent?” in an interview?**

**Answer:** A system is not reliably agentic merely because its prompt says “You are an agent,” it returns JSON, or it calls a tool exactly once. A deterministic pipeline can use an LLM without delegating open-ended next-step selection.

<a id="1-4-agent-vs-chatbot-vs-workflow"></a>
### 1.4 Agent vs Chatbot vs Workflow

**Q55. [Conceptual] Explain Agent vs Chatbot vs Workflow in simple, interview-ready language.**

**Answer:** A chatbot primarily communicates with a user. An agent can select actions from tools. A workflow encodes a defined process in application logic. These labels overlap: a chatbot can contain an agent, and an agent can be just one step inside a workflow.


**Q56. [Interview] Why does Agent vs Chatbot vs Workflow matter, and what is one important design implication?**

**Answer:** Decision test: If you can specify the steps and branches completely in code, begin with a workflow. If the system must repeatedly decide which permitted step to attempt next from uncertain evidence, consider a bounded agent. If it must wait across hours or days, add durable orchestration rather than only a bigger prompt.


**Q57. [Scenario] You must choose between the options in Agent vs Chatbot vs Workflow for a agent handling customer requests. What would you compare?**

**Answer:** Use the distinction stated in the notes: Decision test: If you can specify the steps and branches completely in code, begin with a workflow. If the system must repeatedly decide which permitted step to attempt next from uncertain evidence, consider a bounded agent. If it must wait across hours or days, add durable orchestration rather than only a bigger prompt. Compare correctness, operating constraints and the actual workload before choosing.
