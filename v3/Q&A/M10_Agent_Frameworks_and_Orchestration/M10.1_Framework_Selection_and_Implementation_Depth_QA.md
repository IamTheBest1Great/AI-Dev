**Q9. [Conceptual] Explain Part 1 — M10.1.1 What to Learn Deeply in simple, interview-ready language.**

**Answer:** An agent framework packages primitives that you would otherwise build: execution scheduling, state propagation, tool invocation, pause/resume, streaming, and tracing. ## Part 2 — LangGraph Mental Model and Architecture

**Q27. [Conceptual] Explain Part 2 — LangGraph Mental Model and Architecture in simple, interview-ready language.**

**Answer:** State is the typed data shared by graph nodes. Examples: request text, task phase, evidence references, proposed action, approval decision, attempt count, error, and output. A node normally receives current state and returns updates instead of directly mutating the shared object. Define which fields overwrite and which accumulate using reducers.


**Q28. [Interview] Why does Part 2 — LangGraph Mental Model and Architecture matter, and what is one important design implication?**
